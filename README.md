# 🌿 红山动物星球 Demo

AI 引导下的动物园沉浸式游览 H5 Demo — 游客选择动物身份，以动物视角探索南京红山森林动物园。

## ✨ 核心功能

- 🦊 **9 种动物身份** — 细尾獴、小熊猫、雪豹、猎豹、狞猫、东北虎、灰狼、川金丝猴、猕猴
- 🗺️ **24 个场馆** — 大红山、放牛山、小红山、南门新区四大片区
- 🤖 **AI 对话导览** — Qwen-Plus 大模型，按年龄适配 5 级语言风格（L1-L5）
- 📖 **RAG 知识库** — 200 条红山动物园推文与讲解稿，按需检索注入
- 🎤 **语音输入** — FunASR 实时语音识别（需本地代理）
- 🔊 **语音朗读** — Web Speech API，分句朗读 + 语调调整
- 📸 **拍照打卡** — 按动物关系生成专属姿势引导
- 📖 **故事生成** — 游览结束后 AI 生成探险故事

## 🚀 快速开始

### 环境要求

- **Node.js** v18+（运行代理服务器 + 静态服务）
- **现代浏览器**（Chrome / Edge / Safari，需支持 Web Speech API）
- **阿里云百炼 API Key**（需开通 qwen-plus 和 paraformer-realtime-v2）

### 第 1 步：配置 API Key

打开 `js/llm.js`，替换 `apiKey` 为你自己的 DashScope API Key：

```javascript
apiKey: 'sk-your-dashscope-api-key-here',  // ← 替换为你的 Key
```

API Key 申请：https://bailian.console.aliyun.com

### 第 2 步：启动服务

需要启动**两个服务**（开两个终端窗口）：

**终端 1 — 静态文件服务器**
```bash
cd zoo-demo
npx serve .
```

**终端 2 — 语音识别代理**（仅语音输入功能需要）
```bash
cd zoo-demo
node voice-proxy.js
```

### 第 3 步：打开浏览器

访问 `http://localhost:3000`（或 npx serve 提示的端口），允许麦克风权限即可。

## 🎭 你会获得什么样的体验

### 变身动物，每个场馆都有不同故事

你选择一种动物身份后，走进不同场馆会触发不同的剧情体验：

- **回到家了** — 灰狼走进狼馆，红山会用"欢迎回家"的语气，讲家族故事
- **遭遇天敌** — 细尾獴走进猫科星球，红山会压低声音提醒"小心！这是天敌的领地"
- **巡视猎场** — 东北虎走进獐麂坡，红山会用"到了猎场"的语气，讲捕猎技巧
- **拜访远亲** — 雪豹走进中国猫科馆，红山会讲"虽然是远亲，但同属猫科大家族"
- **遇见邻居** — 细尾獴走进长颈鹿馆，红山会聊"在草原上经常一起出没的老邻居"
- **跨大陆做客** — 任意动物走进考拉馆，红山会用"全新世界"的语气介绍澳洲邻居

同一种动物，去不同场馆，听到的故事完全不同。

### 讲解风格会自动适配年龄

输入年龄后，红山会调整说话方式：

- **3-6 岁小朋友**：用叠音和拟声词，"嘘——小声点！你看那只大猫咪在睡觉觉～"
- **7-9 岁孩子**：当小侦探，"你能找出它为什么跑得这么快吗？"
- **10-12 岁少年**：讲因果，"它身上这些花纹，是为了在草丛里隐藏自己"
- **13-17 岁青少年**：聊系统，"从生态视角看，这是捕食者和猎物的协同进化"
- **成年人**：专业科普，"猎豹的捕猎策略体现了行为生态学中的最优觅食理论"

一家人同逛一个馆，大人小孩各听各的版本。

### 你可以怎么和红山互动

- **打字问问题** — 在对话框输入任何关于动物、场馆的问题
- **开口说话** — 点麦克风按钮，按住说话，红山会听懂并回答（需启动语音代理）
- **听红山讲** — 每条回复都有"🔊 朗读"按钮，分句朗读，疑问句升调、感叹句加强
- **拍照打卡** — 每个场馆会推荐一个专属姿势，比如细尾獴在天敌场馆要"匍匐避险"
- **带走故事** — 游览结束，红山把你的冒险编成一个完整故事，可以分享

## ⚠️ 安全提示

- **API Key 仅限本地开发使用**，不要部署到公网前端
- 生产环境需加后端代理：浏览器 → 你的后端（保管 Key）→ DashScope
- 本 Demo 的 `voice-proxy.js` 仅用于本地开发
