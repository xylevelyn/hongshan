陪伴式游览 Agent

红山动物星球

不是冷冰冰的导览器，而是一个会陪你说话的伙伴。
你变身成一种动物，它就按你的身份、年龄、场馆关系陪你走完整个旅程。

🎯 产品定位

面向红山森林动物园游客的 陪伴式 AI 游览 Agent。核心差异在于三点：

🎭

动物身份沉浸

游客选择幻化成一种动物（细尾獴、雪豹、东北虎等 9 种），以动物视角探索场馆，关系类型决定叙事基调。

🎯

年龄自适应讲解

5 级语言风格（L1-L5），从叠音拟声词到生态学术语，一家人同逛一个馆，大人小孩各听各的版本。

🗣️

多轮对话陪伴

不是单向广播，而是可打断、可追问的对话。开口说话、打字提问、听朗读、拍照打卡、带走故事。

🚀 最小 MVP 路径

从核心体验到完整产品，分 6 步走。前 5 步已在本 Demo 中实现。

  1. 身份选择 + 路线规划

    选动物身份、输入年龄、勾选场馆，自动生成游览路线。9 种动物 × 24 个场馆。

  2. 多轮 AI 对话导览

    基于 Qwen-Plus 大模型 + RAG 知识库，按场馆关系和语言风格生成回复，支持流式输出和打断追问。

  3. 语音输入 + 语音朗读

    FunASR 实时语音识别（按住说话）+ Web Speech API 分句朗读（疑问升调、感叹加强、过滤 emoji 和括号）。

  4. 拍照打卡 + 专属姿势

    按动物关系生成拍照姿势引导（如细尾獴在天敌场馆要"警觉避险"，在老家场馆要"回家团聚"）。

  5. 故事生成 + 游览闭环

    游览结束，AI 把整个旅程编成一个故事，融入身份、场馆、拍照记录。

  6. 多用户并发 + 后端部署

    当前为本地 Demo（单用户）。下一步需加后端代理保管 API Key，支持多游客同时在线、游览记录云端保存。

🗺️ 体验阶段

游客从进入到离开，共经历 4 个阶段、14 个步骤。

阶段 1

身份觉醒

阅读隐私说明 → 输入人数和年龄 → 选择动物身份。系统根据年龄自动匹配 L1-L5 语言风格。

阶段 2

路线规划

浏览场馆地图 → 勾选想去的场馆 → 系统按大红山/放牛山/小红山/南门新区四片区生成最优路线，显示总距离和步行时间。

阶段 3

场馆游览

每个场馆包含：进场问候（关系基调）→ 预制问题气泡 → 多轮对话（语音/打字）→ 拍照打卡（专属姿势）→ 快捷导航（餐厅/卫生间/市集）→ 下一站。

阶段 4

故事生成

所有场馆游完 → AI 整合身份、场馆、拍照记录 → 生成完整冒险故事 → 可分享带走。
